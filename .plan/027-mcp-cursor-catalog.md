# Cursor MCP catalog in Settings

## Goal

Bring every MCP namespace Cursor exposes in this workspace into Connect Settings
→ MCP, with enable toggles and Ask / Allow / Deny permissions.

## Shipped

- Expanded catalog (~40 servers): Slack, Gmail, Calendar, Drive, Notion, Linear,
  ClickUp, Granola, Vercel, Render, Supabase, Cloudflare*, Clerk, Figma, Miro,
  Stripe, Phantom, Aave, Circle, Whop, Kraken, Zapier, Apify, X, Cursor Cloud, …
- Categories + search
- **Cursor-Pack aktivieren** (Ask by default), Alle (Ask), Aktive → Allow, Alle aus
- Auth badge for OAuth connectors
- Shortcuts moved to `#shortcuts` (not mixed into MCP)
- MCP near top of settings sidebar
