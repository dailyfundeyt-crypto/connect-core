# Automatisierung hochladen + Claude Routinen

## Composer +

Opens a menu like Grok’s attach popup:

- Dateien anhängen
- Automatisierung hochladen

Upload stores the recipe, queues **Grok `teach_task`** for training, and asks
**Claude** to plan scheduled Routinen.

## Browser panel

Under the live screen, **Routinen** lists Claude-planned drafts (green clock)
plus server routines for that agent.
