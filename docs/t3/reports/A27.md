## 6. Funktionsbeschreibung der Komponenten

### `<BotPane>` (Hauptkomponente)

```tsx
import { BotPane } from "@/components/agents/bot-pane";

// Hinter Flag in detail-panel.tsx (A39/A40 einbinden):
{getT3Flag("mascot") && (
  <BotPane agentId={agent.id} name={agent.name} />
)}
```

- Flag `mascot` aus → `null` (altes Verhalten)
- Flag `cuaMachines` aus → Computer-Tab deaktiviert (grauer Pill)

### Computer-Tab

- Polling auf `GET /api/machines/:machineId/screen?tabOpen=true` (A19-Route)
- Gedrosselt auf max. ~3 fps (350 ms Mindestintervall)
- **Tab-Wechsel stoppt Polling** sofort (active=false → useEffect cleanup)
- Schlafende Maschinen: grauer Avatar + „Der Computer schläft" + Weck-Button
- Klick auf Karte → `POST /api/machines/:id/wake` via `useMachines.wake()`
- Unterschrift: „Bildschirm von \<Bot\>"

### Bibliothek-Tab

- Ruft `GET /api/workspaces/:agentId/files` auf
- Zeigt Ordner zuerst (gelbes Icon), dann Dateien alphabetisch
- Fallback falls Route 404 → Erklärungstext + Workspace-Pfad aus `agentCliConfigQueryOptions`

### Details-Tab

- Importiert `AgentGeneralRegister` aus bestehender `agent-general-section.tsx`
- Keine Änderung an der importierten Komponente

## 9. Risiken & Gegenmaßnahmen

1. **A29 fehlt**: BotAvatarFallback nutzt AbstractAvatar (vorhanden). Kein visueller Bruch, da beide dieselbe Form rendern.
2. **A07-Route fehlt**: Bibliothek-Tab fällt auf Erklärungstext zurück (404-Erkennung in `fetchWorkspaceFiles`).
3. **Polling bei Tab-Wechsel**: Wird sauber durch AbortController und cancelled-Flag im useEffect gestoppt. Test: active=false → kein weiterer fetch.
4. **Maschine ohne agentId-Owner**: Fallback auf sharedDefaultId greift; falls keine Maschine existiert, wird „Kein Computer zugewiesen" angezeigt.
