## 3. Die Flotten-Ansicht

### 3.1 Was drinsteht

| Spalte | Quelle | Herkunft |
|---|---|---|
| Agent (Name, Titel) | `AgentProfileStore.list()` | A07 |
| Status | `scheduler.getFleetStates()` | A08 |
| CLI | `profile.chosenCli` | A07 |
| Tokens heute | Usage-Store, Europe/Berlin-Tag | A17 |
| Kosten heute | dito | A17 |
| Warteschlangenposition | `state.queuePosition` | A08 |
| Letzte Aktivität | `state.lastActivityAt` | A08 |
| Arbeitsordner | `workspaces.list()` | A07 |

Oben draußen: **CPU** (aktuell + 30-Sekunden-Mittel), **Arbeitsspeicher** (frei/gesamt),
**Freier Platz auf dem Systemlaufwerk**, **Zahl der laufenden CLI-Prozesse** und ein
**Drosselungs-Hinweis** — alles aus `getDetailedResourceMetrics()` (A09).

### 3.2 Tabelle *oder* Raster

Beide Ansichten sind **zwei Sichten auf denselben Datensatz**, kein zweiter. Der Wechsel
ist ein Umschalter, kein Navigation. Begründung: die Flotte ist eine Liste, die man
**abgleicht** (welcher Agent wartet?) — dafür ist eine Tabelle richtig. Wer 40 Agenten
auf einen Blick im Kopf haben will, liest die Kacheln. Deshalb beides, deshalb kein
zweiter Bildschirm.

### 3.3 Das Feature-Flag `bridge`

Ist `bridge` aus, rendert `<FleetView />` **nichts** — kein „deaktiviert“-Kasten. Ein
Hinweiskasten auf eine Funktion, die es nicht gibt, wäre eine Anzeige für eine
Abwesenheit. Serverseitig antworten die Routen dann mit **503**.

## 4. Die Massen-Anlage

### 4.1 Der Ablauf

```
┌─ Lesen ────────┐   ┌─ Vorschau ─────────┐   ┌─ Anlegen ────────┐
│ Backlog lesen  │ → │ Name · CLI · Ordner │ → │ POST /batch-create│
│ (Server oder   │   │ Maskottchen, zum    │   │ mit confirm:true │
│  eingefügt)    │   │ Abwählen            │   │                   │
└────────────────┘   └─────────────────────┘   └───────────────────┘
     nur lesen            nur rechnen              nur auf Klick
```

**Stufe 1 und 2 schreiben nichts.** Die Vorschau entsteht im Browser aus einem
**deterministischen Hash** der Ideen-ID — dieselbe Idee ergibt denselben Namen,
denselben Ordnernamen und dasselbe Maskottchen, jedes Mal. Sonst würde die Vorschau
beim erneuten Öffnen anders aussehen als beim Anlegen.

**Stufe 3 ist der einzige schreibende Aufruf.** Er geht mit `confirm: true`.

### 4.2 Die Absicherung (doppelt)

| Schicht | Was sie tut |
|---|---|
| Browser | Der Anlegen-Knopf existiert erst, wenn eine Vorschau existiert. Er ruft `batchCreateAgents({ …, confirm: true })`. |
| Server | `FleetService.createFromIdeas` prüft `request.confirm`. **Ohne `confirm: true` wird nichts angelegt** — es gibt keine Möglichkeit, durch Weglassen des Flags doch anzulegen. |

Der Server prüft außerdem jede Idee erneut (`sanitizeIdea`): ein manipuliertes
`fetch` aus dem Browser kann keine unbekannte CLI und keinen beliebigen Namen
einschleusen.

### 4.3 Das Backlog-Format

```markdown
| ID | Idee | CLI | Agent | Beschreibung |
|----|------|-----|-------|--------------|
| I1 | Nutzung & Limits | codex | Nova Limits | Baut die Nutzungsansicht |
```

- Eine Zeile **ohne „Idee“** wird **nicht** angelegt und in der Vorschau als Fehler
  gemeldet — sie verschwindet nicht lautlos.
- Eine **unbekannte CLI** macht die Zeile ebenfalls unlesbar. Ein Tippfehler soll
  auffallen, nicht stillschweigend auf `codex` umfallen.
- Zwei Zeilen mit **demselben Agenten-Namen** werden abgefangen (ein Name, ein Agent).
- Fehlt die Spalte „Agent“, wird der Name aus der Idee abgeleitet.

## 8. Offene Punkte (bewusst offen)

1. **Der Mount fehlt** (A37). Ohne ihn liefert `/api/t3/fleet` 404 — die Komponente
   zeigt dann eine leere Flotte statt eines Fehlers. Bewusst so: ein Fehlerbildschirm
   für einen noch nicht gemounteten Endpunkt wäre eine Anzeige für einen Bauzustand.
2. **Der Nutzungsteil (A17)** wird über eine injizierbare Schnittstelle angebunden. Solange
   A17 keinen fertigen Adapter für „Tokens je Agent für heute“ hat, bleiben diese Spalten 0.
3. **Die Vorschau-Ordnernamen sind eine Vorhersage.** Der Server vergibt den endgültigen
   Namen (und hängt bei Gleichheit `-2` an). Die Spalte in der Vorschau ist deshalb mit
   „Arbeitsordner“ überschrieben, nicht mit „Arbeitsordner (endgültig)“.
