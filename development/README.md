# Development Tools & Launchers

Dieser Ordner bündelt alle Entwicklungs- und Startskripte für Connect auf Windows und WSL:

- `START-CONNECT-BROWSER.cmd`: Startet die native Connect Desktop-Anwendung mit integriertem WebView2 AI-Browser.
- `START-PC.cmd`: Startet den gesamten Stack (API auf :3001 + Web-UI auf :3010) und öffnet die Sign-in Seite.
- `activate-google-oauth.sh`: Skript zur interaktiven Aktivierung von Google OAuth im lokalen Stack.
- `scripts/`: Interne Hilfsskripte für Build, Neustart und Tests.
